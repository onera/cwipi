# Community and Support

Welcome to the **CWIPI** community! Whether you are a user or a developer, here is how you can interact with us.


## Support and Assistance

If you encounter difficulties using **CWIPI**, have questions about a feature, or want to report a problem, please use our [GitHub Issues section](https://github.com/onera/cwipi/issues). This is the primary channel for technical support and usage assistance.

Before opening a new Issue, please search the existing ones to see if your question or bug has already been addressed.

### 1. Asking Questions
If you need help using the library or understanding a feature:
* Open a new Issue and apply the **`question`** label.
* Be as specific as possible about what you are trying to achieve.

### 2. Reporting Bugs or Problems
If you find a bug, please open an Issue with the **`bug`** label. To help us resolve it quickly, your report **must** include:
* **Clear steps to reproduce** the problem (ideally with a minimal, self-contained code snippet).
* **Expected vs. actual behavior**.
* **Your environment details:** Operating system, compiler, MPI implementation, and the specific version/commit of **CWIPI** you are using.


## Development Ecosystem

**CWIPI** is a research-grade library developed by ONERA. It provides a comprehensive set of geometric algorithms and mesh manipulation features tailored for massively parallel distributed environments. While its developments aim to meet both internal requirements and the needs of the aerospace research community, we highly value community feedback:

* **Roadmap:** Core developments are defined by the ONERA development team. Major proposals from the community are discussed via GitHub Issues.
* **Internal Mirroring:** The ONERA development team is still using an internal GitLab server. Be aware that there may be a slight delay between internal developments and their public release on GitHub.


## Code of Conduct

We are committed to providing a friendly and inclusive environment. Please be respectful in all your communications.
